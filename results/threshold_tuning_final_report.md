# 诊断阈值调优交叉验证报告

## 1. 实验设计

### 1.1 数据集
- **总样本数**：105 条
- **数据格式**：JSONL 格式，包含图像和文本概率分布
- **分组策略**：采用 group split，按 sample_id 分组

### 1.2 交叉验证设置
- **K 值**：5 折
- **随机种子**：42（确保结果可复现）
- **每折样本数**：21 条
- **分组方式**：按 sample_id 分组。若 sample_id 与病例级实体一一对应，则可有效避免同一病例跨 fold。后续如存在同图多轮或同病例多文本样本，建议改用 case_id / trace_root_id / image_id 进行分组。

### 1.3 阈值配置
- **配置文件**：`configs/threshold_grid_fast.yaml`
- **搜索策略**：网格搜索（108 个组合）
- **评估指标**：准确率、自动完成精度、确认率、误放行率

## 2. 结果分析

### 2.0 指标定义

| 指标 | 计算公式 | 说明 |
|------|----------|------|
| 准确率 | 正确样本数 / 总样本数 | 整体诊断正确性 |
| 自动完成精度 | 自动完成且正确样本数 / 自动完成样本总数 | 自动完成样本的正确性 |
| 确认率 | 进入确认流程样本数 / 总样本数 | 需要人工干预的比例 |
| 误放行率 | 应确认但未确认且错误的样本数 / 总样本数 | 高风险样本的误处理率 |

## 3. 结论

采用 5 折交叉验证后，当前阈值配置在验证集上取得了较稳定的性能：平均准确率为 96.19% ± 0.89%，平均确认率为 7.61% ± 0.98%，自动完成精度为 100.00%。在本次验证样本中未观察到误放行样本，说明该配置在效率与安全性之间取得了较好的平衡。

对于高风险桶（conflict: n=1, both_weak: n=2），当前结果方向上是积极的，但由于样本量较小，其统计结论仍需谨慎解释。

综合来看，该配置已具备小规模试运行或灰度验证条件；若作为正式上线依据，仍建议补充更大规模、按病例级分组的外部验证样本，并保留独立 hold-out 集做最终确认。

**后续建议**：
- 单独保留一个最终 hold-out 集（20-30 条）进行最终确认
- 扩大高风险桶的样本量，提高统计稳健性
- 定期重新评估阈值，适应数据分布变化

## 4. 最优阈值配置

```yaml
# 最优阈值配置（完整参数）
thresholds:
  # 图像相关阈值
  image_top1_threshold: 0.65  # 图像可靠判定阈值
  image_margin_threshold: 0.15  # 图像类别间距阈值（默认值）
  
  # 文本相关阈值
  text_top1_threshold: 0.40  # 文本可靠判定阈值
  text_margin_threshold: 0.10  # 文本类别间距阈值（默认值）
  
  # 弱冲突相关阈值
  weak_conflict_min_image_top1: 0.50  # 弱冲突图像触发阈值（默认值）
  weak_conflict_min_text_top1: 0.40  # 弱冲突文本触发阈值（默认值）
  
  # 全局阈值
  diagnosis_conf_threshold: 0.50  # 诊断置信度阈值
  low_margin_threshold: 0.03  # 低margin阈值
```

**说明**：本次调优对 `image_top1_threshold`、`text_top1_threshold`、`diagnosis_conf_threshold` 和 `low_margin_threshold` 进行了网格搜索，其余阈值保持为系统默认值。

## 5. 阈值解释

| 参数 | 含义 | 当前值 |
|------|------|--------|
| diagnosis_conf_threshold | 全局低置信度确认阈值 | 0.50 |
| low_margin_threshold | top1-top2 过近时的确认阈值 | 0.03 |
| image_top1_threshold | 图像 reliable 判定阈值 | 0.65 |
| image_margin_threshold | 图像类别间距阈值 | 0.15 |
| text_top1_threshold | 文本 reliable 判定阈值 | 0.40 |
| text_margin_threshold | 文本类别间距阈值 | 0.10 |
| weak_conflict_min_image_top1 | 弱冲突图像触发阈值 | 0.50 |
| weak_conflict_min_text_top1 | 弱冲突文本触发阈值 | 0.40 |
